# Study notes

Built by doing: each topic has a concept note, a problem index, and one file per problem with your own attempt, the hints you needed, and the mistake pattern.

Domains: `DSA/`, `system-design/`, `OOPS/`, `DB/`, `AI/` (add `java/`, `cloud/` when needed).

Create a topic: `/coach-notes new DSA two-pointers`
Log a problem: happens at the end of `/coach-review`, or `/coach-notes log DSA two-pointers two-sum-ii`
Daily revision queue: `/coach-notes revise`
Rebuild this index: `/coach-notes index`

Reference solutions stay LOCKED until you finish your own or explicitly ask to reveal.
